Apple Silicon · MLX · 本地推理服务

在 Mac 上做本地推理
按真引擎的方式。

Terrazzo 把 DeepInfer 的 paged-KV 调度器移植到单台 Mac，封装成 OpenAI 与 Ollama 兼容 API，并针对真实 agent 流量里那段很长的共享系统提示做「启动预注册」前缀缓存。

预注册是差异点

预注册前缀 = 在流量到来前把 prefill 做一次。2k / 4k / 8k 共享提示的冷启动首 token：

纯 warm 复用：Ollama 仍然更快

完全相同的提示再次请求时，Ollama 在 2k–8k 只要 0.033–0.060 s， Terrazzo 为 0.081–0.153 s。我们的优势是「新共享提示的第一次请求」， 不是纯缓存命中。

赢在哪里，输在哪里

赢

单机 agent 流量

16 并发会话吞吐是 Ollama 的 2.2×；2k–8k 共享提示预注册后首 token 快 10–50×； 单流和 4 会话延迟优于 vLLM-Metal。一个进程同时说 OpenAI 与 Ollama， 带 tools、JSON Schema 和模型管理。

输

规模化吞吐与冷前缀复用

vLLM-Metal 的 16 会话吞吐（122.1 vs 88.7 tok/s）和 TTFT（1.57 vs 2.56 s）更好； Ollama 在不预注册的冷 prefill 和纯 warm 前缀复用上更快。 没有 Ollama registry、没有 GGUF、没有 embeddings、单机单模型。

诚实总结：Terrazzo 是「一台 Apple Silicon 上的 agent 推理网关」， 不是 vLLM 的规模化吞吐替代品。当初想改变内存叙事的 paged 共享方案实测失败， 数据保留在 BENCHMARKS 里。

里面有什么

Paged KV 引擎

块管理 + 引用计数、连续批处理、round-robin chunked prefill、LCFS 抢占。

前缀缓存

精确共享前缀快照、首批自动注册、/v1/prewarm 与 --system-file 让首次请求零 prefill。

OpenAI + Ollama API

chat/completions、流式、JSON Schema 约束解码、tools/function calling、Ollama NDJSON 接口。

Ollama 风格 CLI

run、pull、list、show、rm、cp、create -f Modelfile、ps、prewarm。

生产级加固

常量时间鉴权、可选 TLS、限流、并发上限、请求 deadline、worker hang watchdog。

可靠的测试

226 个核心测试 + 31 个内核测试、MLX-free CI job、固定 MLX 版本、runtime patch 兼容契约。

跑起来

shell
# 克隆 + 安装（Apple Silicon，macOS 14+）
git clone https://github.com/louisyeaaah/terrazzo.git
cd terrazzo
python3 -m venv .venv && . .venv/bin/activate
pip install -e . -c constraints.txt

# 拉模型、起服务
terrazzo pull mlx-community/Qwen3-4B-4bit
terrazzo serve --model Qwen3-4B-4bit --port 8080 \
    --profile agent --system-file system.txt
OpenAI / Ollama API
# OpenAI 兼容
curl localhost:8080/v1/chat/completions \
  -H 'Content-Type: application/json' -d '{
  "model": "terrazzo",
  "messages": [{"role":"user","content":"解释一下 KV cache。"}],
  "max_tokens": 128
}'

# 预注册共享前缀（或启动时 --system-file）
terrazzo prewarm --base http://127.0.0.1:8080 \
    --system-file system.txt

# Ollama 原生风格
curl localhost:8080/api/chat -d '{
  "model":"terrazzo","stream":false,
  "messages":[{"role":"user","content":"你好"}]
}'
